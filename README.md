# Java + Spring Boot Bootcamp

A hands-on bootcamp covering Java fundamentals, Spring Boot development, microservices, security, and deployment.

## Schedule

| Date    | Topics                                                                    |
| ------- | ------------------------------------------------------------------------- |
| June 1  | Java OOP, Exception Handling, Debugging                                   |
| June 2  | Spring Basics, IoC, Dependency Injection, Beans, Maven, Spring Boot Setup |
| June 3  | REST APIs, MVC Architecture, Layered Architecture, CRUD APIs, Postman     |
| June 4  | Hibernate, JPA, Entities, Repositories, Database Integration              |
| June 5  | DTOs, Validation, Exception Handling, Building a Complete Service         |
| June 8  | Introduction to Microservices, Building User Service                      |
| June 9  | Building Order Service, Inter-Service Communication                       |
| June 10 | Spring Security Fundamentals, Securing REST APIs                          |
| June 11 | Aspect-Oriented Programming (AOP), Logging, Cross-Cutting Concerns        |
| June 12 | Docker Basics, Containerization, Cloud Deployment                         |

## Learning Outcomes

By the end of this bootcamp, you will be able to:

* Apply Object-Oriented Programming principles in Java
* Build RESTful APIs using Spring Boot
* Integrate applications with databases using JPA/Hibernate
* Implement validation and exception handling
* Develop and connect microservices
* Secure APIs using Spring Security
* Use AOP for logging and common concerns
* Containerize applications with Docker
* Deploy services to the cloud
