# Java Day 2

In today's session we covered Java fundamentals including data types (primitive and non-primitive), wrapper classes, stack vs heap memory, the new keyword, arrays, collections, and object creation. It also explored Object-Oriented Programming (OOP) concepts such as Encapsulation, Inheritance, Polymorphism, Abstraction, interfaces, abstract classes, method overloading/overriding, and the Diamond Problem in inheritance.

To refer the notes you can visit this link - https://www.notion.so/Java-Advanced-Concepts-Day2-3736b1fccd3a809d96e8fe18d12831ca?source=copy_link

For the assignment part - Try to enhance Calculator application using method overloading and use Object oriented principles to make the calculator safer (use private access modifiers, encapsulation). Have some hands-on using java and IntelliJ IDEA.
